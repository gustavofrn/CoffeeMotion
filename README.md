# CoffeeMotion ☕

Projeto front-end de uma página de cafeteria **Joe's Coffee**, construído com HTML, CSS e JavaScript.

## Sobre

O CoffeeMotion apresenta uma interface temática de cafeteria com seções de conteúdo e recursos interativos. Este repositório reúne o código-fonte para estudo e demonstração de desenvolvimento web.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Estrutura

```text
CoffeeMotion/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Como executar

1. Clone o repositório: `git clone https://github.com/gustavofrn/CoffeeMotion.git`
2. Abra a pasta no Visual Studio Code.
3. Abra `index.html` no navegador ou utilize a extensão Live Server.
